## Publish on GitHub Pages

1. Create a public repository (for a user site, name it `yourname.github.io`).
2. Upload everything inside this folder: `index.html` and the `images` folder. Keep that structure.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. The live site is https://rahulx.com/ — canonical and business schema already point there.
